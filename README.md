## Personal & side projects

### [PerSeo Insights](https://insights.perseodesign.com)

A **Python/Flask SaaS** for technical SEO, performance, accessibility and security analysis.

Features include site crawling, monitoring, reporting, REST APIs and AI capabilities such as **AI Visibility**, **AI Overview Readiness** and **Perseo Assistant**, which provides contextual answers using website scans and available Search Console data.

👉 [insights.perseodesign.com](https://insights.perseodesign.com)

### [Perseo RAG](https://github.com/giovannimanetti11/perseo-rag)

An open-source, provider-agnostic **Retrieval-Augmented Generation (RAG)** framework built with Python, FastAPI, PostgreSQL and pgvector.

Supports hybrid search, versioned document ingestion, grounded citations, evidence validation and data isolation.

👉 [GitHub repository](https://github.com/giovannimanetti11/perseo-rag)

### [PerseoNXT](https://github.com/giovannimanetti11/PerseoNXT)

The frontend behind [WikiHerbalist](https://wikiherbalist.com), built with **Vue 3, Nuxt 4 and TypeScript**.

Uses headless WordPress, GraphQL, SSR, multilingual content, Algolia, automated testing and GitHub Actions.

👉 [GitHub repository](https://github.com/giovannimanetti11/PerseoNXT)  
👉 [wikiherbalist.com](https://wikiherbalist.com)

### [Simple Donation](https://github.com/giovannimanetti11/Simple-donation)

An open-source **PayPal donation module for Nuxt 3 and Nuxt 4**, featuring configurable amounts, multiple currencies, multilingual support and customizable components.

Listed in the **official Nuxt modules directory** as a third-party Payment module.

👉 [GitHub repository](https://github.com/giovannimanetti11/Simple-donation)  
👉 [Nuxt modules PR #1658](https://github.com/nuxt/modules/pull/1658)

### [Italian Web Accessibility Study (IWAS)](https://github.com/giovannimanetti11/italian-web-accessibility-study)

A reproducible accessibility study covering **10,022 Italian .it domains and 34,641 evaluated pages**.

Built with Python, Playwright and axe-core to measure automatically detectable WCAG accessibility barriers.

👉 [GitHub repository](https://github.com/giovannimanetti11/italian-web-accessibility-study)  
👉 [Paper on Zenodo](https://doi.org/10.5281/zenodo.23347092) · [Dataset](https://doi.org/10.5281/zenodo.23346985)

### [Italian Web Security Study (IWSS)](https://github.com/giovannimanetti11/italian-web-security-study)

A large-scale analysis of security configurations across **10,022 Italian .it domains**, covering HTTP headers, TLS, DNS, CSP, cookies and other publicly observable security signals.

Includes a reproducible Python pipeline, statistical analysis and a public dataset.

👉 [GitHub repository](https://github.com/giovannimanetti11/italian-web-security-study)  
👉 [Paper on Zenodo](https://doi.org/10.5281/zenodo.21322437)
